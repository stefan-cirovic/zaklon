# Zaklon logo

The mark is a dome over the horizon with a warm light inside, its reflection below (the lower line in the color of the light) and two stars.

| File | Use |
|---|---|
| `zaklon-icon.svg` | App icon (dark tile). |
| `zaklon-icon-small.svg` | App icon at 32 px and below (favicon), with heavier lines. |
| `zaklon-icon-light.svg` | App icon on a light tile. |
| `zaklon-mark.svg` | The mark alone, for dark backgrounds. |
| `zaklon-mark-small.svg` | The mark alone at small sizes, with heavier lines. |
| `zaklon-mark-light.svg` | The mark alone, for light backgrounds. |

Wordmark: "ZAKLON" in Sora Light (300), letter spacing 0.32em.

## Colors

All colors are solid; the logo uses no transparency.

| Name | Hex |
|---|---|
| Background | `#0B0D12` |
| Surface (cards, icon tile) | `#151923` |
| Line | `#2A303C` |
| Text | `#ECE7DD` |
| Secondary text | `#A7ADB8` |
| Light (accent) | `#F2B366` |
| Reflection, near | `#8C8983` |
| Reflection, far (same as the light) | `#F2B366` |
